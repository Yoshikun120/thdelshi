DELshi.que — วิธีเปิดเว็บและเพิ่มข้อมูล

1) แตกไฟล์ ZIP
2) เปิด index.html ผ่าน local web server หรืออัปโหลดโฟลเดอร์นี้ขึ้น GitHub
   แล้วเปิด Settings > Pages เพื่อเผยแพร่เว็บ
3) เพิ่มข้อมูลที่ได้รับอนุญาตใน data/database.txt

รูปแบบไฟล์ TXT:
NAME: ชื่อที่ต้องการค้นหา
REF: รหัสอ้างอิงภายใน (ห้ามใช้เลขบัตรประชาชน)
CATEGORY: หมวดหมู่
STATUS: สถานะ
NOTE: หมายเหตุ

เว้นบรรทัดว่างระหว่างแต่ละรายการ

ข้อจำกัดและความปลอดภัย:
- รหัสผ่านใน script.js เป็นเพียงประตูกั้นหน้าเว็บ ไม่ใช่ระบบรักษาความปลอดภัย
  เพราะผู้เข้าชมสามารถดูโค้ดและอ่านรหัสผ่านได้
- GitHub Pages เป็น static hosting และไฟล์ database.txt ที่เผยแพร่จะเป็นสาธารณะ
- ห้ามใส่เลขบัตรประชาชน ที่อยู่ เบอร์โทร หรือข้อมูลส่วนบุคคล/ข้อมูลอ่อนไหว
- ตัวอย่างนี้ค้นหาด้วยชื่อและ REF ที่เป็นรหัสภายในเท่านั้น ไม่รองรับการค้นด้วยเลขบัตรประชาชน
- หากต้องใช้ข้อมูลส่วนบุคคลจริง ต้องใช้ backend ที่มีการยืนยันตัวตนและกำหนดสิทธิ์
  ไม่ใช่เก็บ TXT ไว้ใน repository สาธารณะ
